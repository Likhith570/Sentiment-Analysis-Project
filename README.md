# Sentiment-Analysis-Project
Sentiment Analysis of Restaurant Reviews
This project implements a Machine Learning pipeline to perform sentiment analysis on restaurant reviews. Using Natural Language Processing (NLP) techniques, the model classifies reviews as either Positive or Negative.

 Features
Data Preprocessing: Cleans review text by removing non-alphabetic characters, converting to lowercase, removing stop words, and applying stemming.

Text Vectorization: Uses CountVectorizer to convert processed text into numerical features.

Model: Utilizes a Multinomial Naive Bayes classifier.

Evaluation: Assesses performance using Accuracy, Precision, Recall, and a Confusion Matrix.
